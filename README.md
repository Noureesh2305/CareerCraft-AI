# 🎯 CareerCraft AI – Resume, Skill & Interview Assistant

CareerCraft AI is a student-focused AI application that helps users analyze resumes, identify skill gaps for specific job roles, practice interview questions, and receive AI-based feedback. The project is designed to be simple, explainable, and beginner-friendly.

---

## 🎯 Objectives
- Analyze resumes and extract relevant skills  
- Compare skills with job role requirements  
- Calculate a resume score  
- Provide structured interview practice  
- Generate personalized feedback and insights  

---

## ✨ Features
- Resume upload and text extraction (PDF)  
- Technical and soft skill identification  
- Skill gap analysis for selected job roles  
- Resume scoring based on simple logic  
- Interview questions by category and difficulty  
- Tone-based feedback for interview answers  
- Dashboard with visual summaries  

---

## 🛠️ Technologies Used
- Python  
- Streamlit  
- Pandas, NumPy  
- NLTK (VADER Sentiment Analysis)  
- Plotly  
- PyPDF2

---

## ⚙️ How It Works
1. User uploads a resume in PDF format  
2. Resume text is extracted and cleaned  
3. Skills are identified and compared with job roles  
4. Resume score is calculated  
5. Interview questions are generated  
6. User answers are analyzed for tone  
7. Feedback and dashboard are displayed  

---

## ▶️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py

```
